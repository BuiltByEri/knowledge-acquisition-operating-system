# Northstar Knowledge Catalog Example

Northstar Knowledge Catalog is a fictional example source used to demonstrate KAOS without private project, client, or domain-specific references.

The example contains product, policy, course, service, and research records from five fictional source surfaces. It demonstrates duplicate handling, alias preservation, variant resolution, canonical proposals, approved canonical entities, deferred or rejected proposals, non-canonical records, provenance, conflicts, retrieval exposure, and downstream readiness for indexing or retrieval.

No working RAG system, search engine, database, or orchestrator is implemented by this example.

## Source Surfaces

- Northstar Product Index
- Northstar Policy Library
- Northstar Course Directory
- Northstar Service Catalog
- Northstar Research Archive
