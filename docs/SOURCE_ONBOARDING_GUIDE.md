# Source Onboarding Guide

Use this guide to start a KAOS acquisition for a new source.

## Flow

1. Run Source Boundary Audit.
2. Run Acquisition Strategy.
3. Run Knowledge Inventory.
4. Run Baseline Reconciliation.
5. Run Editorial Triage.
6. Run Canonical Readiness Review only when new canonical entities are proposed.
7. Run Implementation Planning.
8. Run Implementation Approval.
9. Run Structured Data Implementation.
10. Run Post-Implementation Review.
11. Run Source Certification.
12. Run Source Completion.

## Guardrails

- Do not create canonical entities by inference.
- Do not erase source truth during normalization.
- Do not expose non-canonical source records to retrieval without a governed decision.
- Do not skip approval gates.
- Do not perform repository workflow actions as a KAOS skill.
