# Versioning Policy

KAOS uses Semantic Versioning.

The approved public release uses version `1.0.0`.

## Skill States

- `Draft`
- `Under Review`
- `Approved`
- `Deprecated`
- `Retired`

Approved public skills use `Approved`. Future candidate skills must remain in the appropriate pre-release state until Product Review approves them.

## Version Rules

- MAJOR changes alter lifecycle, required metadata, approval gates, status values, decision values, or artifact ownership.
- MINOR changes add backward-compatible optional capabilities.
- PATCH changes clarify wording without changing behavior.
