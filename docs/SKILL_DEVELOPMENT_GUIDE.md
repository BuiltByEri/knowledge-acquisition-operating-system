# Skill Development Guide

Use this guide when creating or revising KAOS skills.

## Rules

- Preserve the approved lifecycle.
- Keep status separate from decision.
- Keep record-level outcomes separate from KAOS decisions.
- Keep artifact ownership explicit.
- Keep approval authority in the owning skill.
- Keep repository workflow actions outside KAOS skills.
- Derive examples from fictional or public-safe material only.

## Required Shape

Each skill must include a `kaos_skill` metadata block and the 19 required human-readable sections listed in `core/KAOS_SKILL_SPECIFICATION.md`.
